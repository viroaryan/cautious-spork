# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability
We take the security of ReelShield AI seriously. If you discover a security vulnerability, please do NOT create a public issue.

Instead, please send an email to `security@reelshield.ai` or contact the maintainers directly through GitHub private security advisories.

Please include:
1. Type of issue (e.g. buffer overflow, path traversal, denial of service).
2. Proof-of-concept steps or malicious payload sample.
3. Impact assessment.

We strive to respond to all reports within 48 hours and release patched versions promptly.
